# Explorium

**Explorium** is an open-source Chromium-based browser project inspired by Internet Explorer and the Windows 8.1 Metro design language.

## Project status

🚧 Early development

The first development target is **Explorium ARM**.

## Planned targets

| Target | Architecture | Package | UI |
|---|---|---|---|
| Explorium ARM | ARM64 | `.appx` | Metro |
| Explorium AMD64 | AMD64 / x64 | `.exe` | Desktop |

## Planned features

- Chromium-based rendering engine
- Windows 8.1-inspired Metro interface
- ARM64-first development
- TLS 1.3 support
- Optional Copilot integration, **disabled by default**
- Open-source development

## Development

The project is developed using **Microsoft Visual Studio**.

The ARM64 build is the first priority. The AMD64 desktop build will follow after the ARM foundation is established.

## Name

**Explorium** combines the idea of exploring the web with the legacy Internet Explorer concept.
